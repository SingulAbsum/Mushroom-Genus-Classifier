# Mushroom-Genus-Classifier
Demo Instructions:
The installations neccesarry with the command to install them is
pip install streamlit torch torchvision numpy scikit-learn matplotlib seaborn pillow joblib
and to run the demo:
python -m streamlit run demo.py
to properly run change the directory paths or names of the directory files for the cnn model load which is a ".pth" as well as the svm model load which is a ".joblib"
The implemented AI approach is that of a mied CNN+SVM approach,CNN for feature detection and SVM as a better classifier head.
The jypiter notebook klajdi_murataj_mikael_xhangolli_code.ipynb isn't of interest to run unless inspecting or retraining parameters and unfreezing the completely frozen model.
However,during the run if an error where  a variable isnt defined yet ,just run the next 2-3 next snippets and rerun the error one.
